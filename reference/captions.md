# Субтитры

Субтитры — строго по словам распознавания (`words.json` основы). Текст слов правится в EDL (`replace`, `retime`, `override`), не в кадре.

## Карточки

Группировку делает `plan` одинаково для всех стилей, параметры — `style.json → captions` (их можно переопределить в таймлайне):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `max_words` | 3 | слов в карточке |
| `max_chars` | 16–18 | знаков в карточке (по верхнему регистру) |
| `pause` | 0,35 | пауза между словами, после которой — новая карточка |
| `lead` / `tail` | 0,04 / 0,30 | карточка появляется до первого слова и держится после последнего |
| `hang` | true | висячий предлог («в», «на», «и») уходит в следующую карточку |
| `split_on_cuts` | false | карточка не переживает склейку |

Разрыв карточки — также на знаке препинания и перед словом с заглавной. Принудительный разрыв перед словом — `captions.breaks: [номер слова]` в таймлайне. Номера слов печатает `reel.py words work/words.json`.

## Вид

Вид задаёт стиль. У базовых компонентов — четыре варианта (`captions.variant`):

| Вариант | Как выглядит |
|---|---|
| `clean` | белый текст с обводкой, слово проявляется с подъёмом при произнесении |
| `pop` | каждое слово «выпрыгивает» 0,7 → 1,12 → 1 за 5 кадров на своём старте |
| `karaoke` | вся карточка видна сразу, текущее слово на плашке акцентного цвета |
| `marker` | как pop, ключевое слово — на маркере тёмным текстом |

Токены: `font`, `weight`, `size` (72–84), `color`, `stroke`, `stroke_color`, `shadow`, `accent_color`, `highlight`, `karaoke_text`, `case` (`upper` | `as-is`), `bottom` (низ строки, по умолчанию 1488), `max_w`.

Пресеты рисуют субтитры своими компонентами: sticker — pop со словом на маркере, premium — белые, слово встаёт при произнесении, ключевое тёплым цветом, kinetic — слова встают на ребре, ключевое на красной плашке. Смесь «плашки одного стиля, субтитры другого» — `components: {"captions": "premium"}` (см. `styles.md`).

## Правила

- Не на лице и в окне 73–78 % высоты. Если лицо низко — субтитры поднять (`captions.bottom`) и проверить `qa`.
- Ключевые слова — `captions.accents`: номера слов или сами слова. Одно-два на фразу, не больше.
- Когда плашка дословно повторяет речь (хук, список лида, призыв), субтитры на это время скрыты: `captions.suppress: [[начало, конец], …]` (якоря как везде).
- Время показа текста ≥ 0,3 × слов + 0,5 с. `plan` предупреждает о плашках, которые не успеть прочитать.
- Написание: «ё» где есть, «ёлочки», «кешбэк» через «е». Термины — как принято в теме (проверить с автором).
