# Приёмка — чек-лист

«Готово» говорится только после всех пунктов. Каждый пункт — конечным действием: команда с выводом или просмотр кадров глазами.

## Автоматически — `reel.py qa <таймлайн> --style <стиль>`

- [ ] Кадров = кадры основы + кадры стоп-кадра (`nb_read_frames`, а не длительность).
- [ ] 30/1 к/с, `bt709` во всех трёх метках, `yuv420p`.
- [ ] Длина звука = длина видео ± 0,05 с.
- [ ] −14 LUFS ± 0,5, true peak ≤ −1 dBTP — на итоговом mp4, после AAC.
- [ ] ТГ-версия < 45 МБ и ≤ 6 Мбит/с.
- [ ] Рамки всех текстов с непрозрачностью ≥ 0,5 — в безопасной зоне на каждом кадре. Выход за зону короче 6 кадров подряд (перелёт пружины на входе, тряска удара) печатается отдельно и ошибкой не считается: так было и в принятых роликах.
- [ ] Накладки не пересекают лицо на каждом кадре (с учётом панч-ина).
- [ ] Каждый SFX — на кадре появления своего слоя ±1.
- [ ] `--stt`: обратная расшифровка — фразы целые, без обрубков и повторов.

Код выхода 1, если хоть один пункт FAIL.

## Глазами — `reel.py sheet` (через Read, в полный размер)

- [ ] Весь ролик через 0,25 с (`sheets/every025_*.jpg`).
- [ ] Каждый кадр вокруг появлений накладок и склеек (`sheets/events_*.jpg`): ничего не мигает, не обрезано, нет кадра-пустышки на шве, нет двойной экспозиции текста.
- [ ] Кадр 0 — обложка: плашка хука видна целиком, жест указывает на неё.
- [ ] Структура шаблона видна без звука: хук, лид, номера блоков, петли, призыв.
- [ ] Цифры в кадре совпадают с голосом и появляются в момент произнесения.
- [ ] Плашка не «квадратная»: форма, вход с перелётом, микродвижение (`reference/motion.md`).

## Файл

- [ ] Пишется во временное имя (`.имя.part.mp4`) и переименовывается в конце — `finalize` делает так сам. Не брать и не отправлять файл, пока идёт запись: недописанный mp4 без `moov` не откроется.
- [ ] Обложка `<name>_cover.jpg` = кадр 0.
- [ ] Если исходники с айфона — HDR-меток в итоге нет (`color_transfer` не `arib-std-b67`).
