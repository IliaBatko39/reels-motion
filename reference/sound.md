# Звук

Всё делает `reel.py audio` по стилю (`style.json → audio`). Внешних файлов и лицензий нет: SFX и музыка синтезируются numpy.

## Голос — только гигиена

- `highpass=f=80` и мягкий компрессор ratio ≤ 3 (`audio.voice` — строка фильтров ffmpeg).
- Без шумодава и «эквалайзера присутствия»: на слух звучит резко, слушатель возвращается к минимальной версии.
- На стоп-кадре — тишина; вход живого звука после неё — с наплывом 5 мс, без щелчка.
- Склейки в `cut` — с краями 12 мс.

## SFX — синтез, ровно на кадр появления

Типы: `pop`, `click`, `whoosh`, `swoosh_down`, `swish`, `riser`, `hit`, `ping`. Уровень задаётся относительно громкости голоса: максимум momentary loudness события = integrated голоса + `audio.sfx[тип]` дБ. Потолок — голос −8 дБ.

| SFX | Обычный уровень | Момент на кадре |
|---|---|---|
| `pop` | −14…−17 | атака на первом видимом кадре плашки |
| `click` | −18…−21 | атака |
| `whoosh` | −12…−17 | пик на шве или на конце въезда |
| `swoosh_down`, `swish` | −14…−20 | пик |
| `riser` | −15…−20 | кончается ровно на кадре шва |
| `hit` | −9…−13 | атака на ударе (кодовое слово, ответ) |
| `ping` | −17 | атака (стеклянный акцент хука) |

События ставят компоненты (`ctx.sfx(t, тип, слой)`), переходы стиля (`transitions.whip.sfx`, `transitions.flash.sfx`) и акцент стоп-кадра (`audio.freeze_accent`). Плотность: не чаще одного SFX в 1,5 с, на субтитры звук не ставится. `qa` проверяет, что слой виден на кадре события ±1.

## Музыка — синтез с sidechain

`audio.music.preset`: `pad` (тёплый пэд и мягкий пульс), `beat` (лёгкий бит), `pulse` (ритм с «насосом»), `none`. Уровень — `level_lu` относительно голоса до приседания, `bpm`, `start` (`"live"` — с конца стоп-кадра).

Приседание под голос: `sidechaincompress` с ключом-голосом (`audio.sidechain`: threshold, ratio, attack, release). Цель — под речью музыка на 15–19 дБ тише голоса; `audio` печатает замер `music_under_speech_db`.

## Мастер

- Двухпроходный linear `loudnorm` → `alimiter … level=false` (`audio.master`: lufs, tp, limit). Без `level=false` лимитер нормализует сигнал к 0 dBFS.
- Итог −14 LUFS ± 0,5, true peak ≤ −1 dBTP после кодирования в AAC. Проверяет `qa`.
- Две версии: `master.wav` (голос + SFX + музыка) и `master_nomusic.wav` — под трендовый звук в приложении.

## Проверка на слух без ушей

`reel.py qa … --stt` — обратная расшифровка готового файла через fal whisper по фразам: фразы целые, без обрубков, повторов и щелчков. Ключ — `FAL_KEY` в окружении.
